# Manipulation Lab

Physical AI manipulation experiments using ROS 2,
RoboManipBaselines, and MuJoCo.

## Objectives

- Robot manipulation simulation with MuJoCo
- Teleoperation and demonstration data collection
- Imitation learning with RoboManipBaselines
- ROS 2 integration
- Future integration with YUBI devices

## Environment

- Windows / WSL2
- Ubuntu 24.04
- Python 3.12
- MuJoCo
- ROS 2 Jazzy
- RoboManipBaselines
